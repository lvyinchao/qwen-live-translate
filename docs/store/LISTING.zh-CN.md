# Chrome 商店介绍 — 简体中文

名称：**TimbraDub 听译 — 原音色视频翻译**

简短说明：**保留原说话人音色，29 种语言同步译音与双语字幕。需自行到 qianwenai.com 注册账号并申请 API Key。**

## 详细说明

用原声的音色，听另一种语言。保留原说话人音色，在原网页播放器中收听译音，跟随原视频时间轴。

听译会提前准备视频后续的译音，再按原语句时间播放。通过 Qwen LiveTranslate 请求保留原说话人音色，并显示双语字幕；音色相似度由模型决定，不承诺口型同步。

全部 29 种译音目标语言：
中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、阿拉伯语、意大利语、印度尼西亚语、泰语、越南语、土耳其语、印地语、马来语、荷兰语、乌尔都语、挪威语（书面语）、瑞典语、丹麦语、希伯来语、芬兰语、波兰语、冰岛语、捷克语、菲律宾语、波斯语。

• 选择检测到的视频和 29 种支持语音输出的目标语言之一。
• 翻译中可换语言：命中缓存直接复用，没有缓存则暂停准备。
• 网页暂停、跳转和 0.5～2 倍速同步作用于译音，已测试网页播放器的容器全屏。
• 分别调整原声和译音音量；原文、译文字幕独立开关，可单开任一种、双开或全关，默认双开。
• 界面支持 English / 简体中文，默认英文；面板产品标题、页面标题和工具栏提示跟随已保存选择，重新打开仍保留。Chrome 扩展管理名称及侧栏外框名称由浏览器语言决定。
• 自动保存文件默认关闭。开启后按语句本地分段暂存，再合并为含 WAV、字幕和双语脚本的单个 ZIP。
• 分别查看播放缓存、归档暂存和临时原媒体空间，停止翻译后可自行清理。

使用前需要用户自行前往 https://qianwenai.com/ 注册账号并申请自己的 API Key，在插件设置中填写密钥、Workspace ID 和对应地域。模型费用由用户自己的账号按实际用量结算，项目不提供公共密钥或免费模型额度。插件没有项目自建后端、订阅、广告或统计。点击开始翻译后，音轨由扩展直接发送至你配置的百炼端点。密钥保存在受限的扩展本地存储，仅用于模型鉴权。

当前为开源预览版。Bilibili 已有真实原网页译音检查，项目仓库按测试版本记录具体结果和当前验收边界，也保留未达标的同步结果。部分实测仍有起播延迟、长句截尾和较多缓冲，倍速时尤其明显，不能保证每句译音完整播放。YouTube 能检测播放器并读取部分窗口，但长时间读取仍有播放验证限制；腾讯视频仅验证了指定明文 HLS 剧集。其他站点被检测到不等于一定可翻译。需要可提前读取的未加密音轨；不支持直播、DRM 解密、完整视频下载或明显滞后的录音翻译模式。全屏检查仅覆盖网页播放器容器，原生视频元素全屏和画中画字幕暂不支持。准备可能需要数十秒，取决于网络和模型。
