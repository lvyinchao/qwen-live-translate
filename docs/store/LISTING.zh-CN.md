# Chrome 商店介绍 — 简体中文

名称：**Qwen Video Dub — 听译视频译音**

简短说明：**在原网页播放器中收听同步译音和双语字幕，支持原音色模式。需自备百炼 API Key。**

## 详细说明

用另一种语言观看支持的网页视频，继续使用熟悉的播放器和时间轴。

听译会提前准备视频后续的译音，再按原语句时间播放。通过 Qwen LiveTranslate 请求保留原说话人音色，并显示双语字幕；音色相似度由模型决定，不承诺口型同步。

• 选择检测到的视频和 29 种支持语音输出的目标语言之一。
• 翻译中可换语言：命中缓存直接复用，没有缓存则暂停准备。
• 网页暂停、跳转、全屏和 0.5～2 倍速同步作用于译音。
• 分别调整原声和译音音量，随时开关双语字幕。
• 界面支持 English / 简体中文，默认英文。
• 自动保存文件默认关闭。开启后按语句本地分段暂存，再合并为含 WAV、字幕和双语脚本的单个 ZIP。

需要你自己的兼容百炼 API Key、Workspace ID 和地域，模型费用由百炼账号结算。插件没有项目自建后端、订阅、广告或统计。点击开始翻译后，音轨由扩展直接发送至你配置的百炼端点。密钥保存在受限的扩展本地存储，仅用于模型鉴权。

当前为开源预览版。Bilibili 已有真实短时译音检查；YouTube 能检测播放器并读取部分窗口，但长时间读取仍有播放验证限制；腾讯视频仅验证了指定明文 HLS 剧集。其他站点被检测到不等于一定可翻译。需要可提前读取的未加密音轨；不支持直播、DRM 解密、完整视频下载或明显滞后的录音翻译模式。准备可能需要数十秒，取决于网络和模型。
