# Brand assets

The logo combines a speech bubble with three descending sound bars that suggest a play triangle. Deep green `#164a3f` and mint `#c7f9d9` follow the existing interface palette. The mark has no embedded text and remains usable at Chrome toolbar sizes.

- Editable source: [`public/brand/logo.svg`](../public/brand/logo.svg).
- Generated toolbar/install icons: `public/icons/{16,32,48,128}.png`.
- High-resolution preview: [`docs/assets/logo.png`](assets/logo.png).
- Project banner: [`docs/assets/banner.svg`](assets/banner.svg).
- Chrome Store promotional tile: `docs/store/assets/small-promo-440x280.png`.
