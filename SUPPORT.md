# Getting help

Read the [English guide](README.md), [中文使用说明](README.zh-CN.md), [compatibility record](docs/VALIDATION.md) and [privacy policy](PRIVACY.md) first.

For a bug, use the [issue form](https://github.com/lvyinchao/qwen-live-translate/issues/new/choose). Include the extension and Chrome versions, OS, public video URL, source position, language pair, and steps. Site detection is different from ahead-readable media support. Mention whether the video is an ad, live, protected or behind a login; never include your login data or bypass instructions.

Feature requests should describe a concrete watching workflow. Please avoid duplicate requests. This is a community preview without a support SLA.

For vulnerabilities or leaked credentials use [Security](SECURITY.md), not a public issue. Provider billing, API access and provider data retention are managed by Alibaba Cloud; the project does not operate those services.
